# Support

## How to get help

- **Bugs / feature requests:** open a GitHub Issue in this repository.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not file public issues for undisclosed vulns.
- **Usage questions:** prefer Issues with the `question` label, or Discussions if enabled.

## What this project is

Installable AI+human engineering guardrails (packs + optional validator). See [README.md](README.md) and [docs/references/install.md](docs/references/install.md).

## Maintainer response

Best-effort for a public OSS project. There is no SLA. Pull requests with clear tests and docs are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
