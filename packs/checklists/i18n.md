# Internationalization checklist

For humans and agents before merging user-visible string or locale changes.

- [ ] New strings use the consumer’s existing catalog / i18n mechanism
- [ ] Keys are stable and follow existing naming
- [ ] Interpolation / plural forms match project conventions
- [ ] Missing-key CI (if present) is green
- [ ] Default-locale examples/docs stay honest
- [ ] New locales or vendors call out human approval
- [ ] RTL / layout impact considered when relevant
