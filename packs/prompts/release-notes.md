# Release notes prompt (Copilot / Claude / Codex)

Paste when drafting GitHub Release notes from CHANGELOG / commits.

```text
Draft release notes for this version from the CHANGELOG entry and recent commits.

Include:
## Highlights
- 3–6 bullets a consumer cares about

## Upgrade notes
- Any stricter default checks or breaking CLI behavior
- Link to ADRs if relevant

## Full changelog
- Point to CHANGELOG.md section

Be accurate; do not invent features. No company names. No secrets.
```
