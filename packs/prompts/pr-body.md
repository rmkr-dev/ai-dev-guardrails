# Pull request body prompt (Copilot / Claude / Codex)

```text
Write a PR description for these commits that a reviewer can use without chat history.

Include:
## Summary
- 2–4 bullets of what changed and why

## Test plan
- [ ] commands or checks to run
- [ ] docs/links to verify
- [ ] any high-impact items needing human approval

Be honest about what is out of scope. No company names. No secrets.
```
