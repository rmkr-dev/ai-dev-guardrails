# Commit message guardrails (Copilot / Claude / Codex)

Use with [core.md](core.md).

## Style

- Conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `ci:`, `chore:`, `refactor:`.
- Subject line: imperative, ≤72 chars, no trailing period required.
- Body: why the change exists; mention risk or follow-ups when useful.
- One logical change per commit when practical; PRs may contain 2–4 commits.

## Do not

- Add Cursor/AI co-author trailers or “generated by” tags
- Put secrets, tokens, or private URLs in messages
- Use vague subjects (`update`, `fixes`, `wip`) for merges intended for `main`
