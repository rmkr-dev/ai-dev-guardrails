# ADR-006: 0.2.x expansion — checks and domain packs

- **Status:** Accepted
- **Date:** 2026-09-14

## Context

After ADR-004 (v0.2.0 suite) and ADR-005 (a11y/data/issue templates), the 0.2.x line added more presence checks (`pre_commit`, `code_of_conduct`, `funding`) and domain packs (supply-chain, privacy, i18n) plus machine-readable CLI output. Consumers need a second milestone note without jumping to a major version.

## Decision

1. Treat **0.2.22+** as the expanded 0.2.x baseline: ~18 presence checks and broader pack coverage.
2. Keep checks presence-oriented (ADR-002); domain judgment stays in packs.
3. JSON `check --format json` is additive and non-breaking.
4. A future **0.3.0** would be reserved for breaking CLI changes, required config files, or non-presence semantics—and would need a new ADR.

## Consequences

- README/architecture should cite ADR-006 when describing the expanded suite.
- Org-wide policy engines, SARIF, and secret scanning remain out of scope.
