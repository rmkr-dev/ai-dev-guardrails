# ADR-004: v0.2 pack and check suite milestone

- **Status:** Accepted
- **Date:** 2026-09-14

## Context

Through 0.1.x the repository grew agent modules (testing, observability, deps), PR-review prompts for Copilot/Claude/Codex, checklists, and presence-oriented validator checks. Consumers need a clear minor milestone that signals a usable default suite without promising a heavyweight policy engine.

## Decision

1. Tag **v0.2.0** when the default CLI includes Dependabot presence checking and the packs cover core, security, secrets, testing, observability, docs, CI, commits, and deps, plus PR-review prompts and key checklists.
2. Remain presence-oriented for checks (ADR-002); content quality stays in packs.
3. Continue 0.2.x for additive packs/checks; breaking CLI changes would require a new major and ADR.

## Consequences

- 0.2.0 is a packaging milestone, not a rewrite.
- Secret scanning, SARIF, and org-wide policy remain out of scope.
